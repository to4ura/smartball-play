# ねこスマートボール

[スマホ・PCで遊ぶ](https://to4ura.github.io/smartball-play/)

右下のレバーを下へ引いて離すと発射。前の猫がレーンを抜ければ次も打てます。飛行中の猫がいない間は、画面のどこでも左右スワイプで穴が回転します。

## ルール

16穴、赤・青・黄・緑の4色の猫。入球は100点。同じ色が上下左右につながって4個以上、または一直線の対角線に4個そろうと、その色のボーナス2,000点を獲得します。玉・穴・色は消えません。色ボーナスは1色につき1盤面で1回だけです。

各色の最大連結数が5個以上なら、4個を超えた1個につき倍率を0.1加算します。離れた組の個数は合算せず、その色の最大の組だけを数えます。複数色の加算分は1倍に足し合わせます。曲がった斜めつながりは対象外です。

盤面の点数 =（入球点 + 4穴ごとの2,000点 + 色ボーナス）× 倍率。4・8・12・16穴が埋まるごとに2,000点を獲得します（色や連結は不問）。16穴の基礎点は入球1,600点＋穴ボーナス8,000点＝9,600点です。クリア時に総得点へ加算し、新しい空の16穴へ進みます。ボーナス獲得状態と倍率はリセットし、床の猫・発射待ちの色順・飛行中の猫は引き継ぎます。以前の盤面の得点に倍率を掛け直すことはありません。

床に10個落ちると終了。その盤面では達成済みの4穴ごとのボーナスも含めて精算します。画面のスコアは確定済みの合計と現在の盤面の暫定点を表示します。新ルールのベストスコアは旧ルールと別に記録します。

| 連結数の内訳 | 盤面クリア得点 |
| --- | ---: |
| 4・4・4・4 | 17,600 |
| 6・5・5 | 21,840 |
| 8・8 | 24,480 |
| 16 | 25,520 |

## オンラインランキング

一時停止・結果画面の「ランキング」で名前・数字4桁のあいことば・猫アイコンを登録。ゲーム終了時に自己ベストを自動登録し、上位25人と自分の順位を表示します。別の端末では「つづきから」で引き継げます。通信失敗時は端末に記録を残して再送します。

## 対戦モード

タイトルから VS CPU、VS 近くの人、VS オンラインを選べます。近くの人は各自のスマホで6桁の合言葉を共有して参加、オンラインは待機中の相手と自動マッチングします。1P（青枠）は青・緑、2P（赤枠）は赤・黄を使います。

1発が入球または落下したら交代。レーンへ戻った猫は同じ人が打ち直します。入球・落下で1発消費し、各13発で終了します。16穴が先に埋まった場合も終了。弱い発射でレーンへ戻った場合は発数を消費しません。

各自の点数 =（自分の入球数×100 + 自分の穴数ボーナス + 自分の色ボーナス）× 自分の倍率。穴数ボーナスは各自の入球4個ごとに2,000点です。色ボーナスと倍率は一人モードと同じ連結判定を使い、自分の2色だけが対象です。同点は引き分け。対戦成績は一人モードのランキングに送信しません。

通信対戦はWeb版で利用します。発射条件と乱数シードを共有して両端末で物理演算し、1P側の入球結果を正として同期します。相手側で発射が再生し終わるまで次の操作を待ちます。CPUは通常の物理演算で発射し、時々穴を回転します。
