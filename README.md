# ねこスマートボール

[スマホ・PCで遊ぶ](https://to4ura.github.io/smartball-play/)

右下のレバーを下へ引いて離すと発射。威力は初期版と強化版の中間に調整しました。前の猫がレーンを抜ければ次も発射できます。左上はカーブで、上部の釘は2本だけ。左の釘をカーブ手前の高い位置へ移し、左端へ偏るルートを減らしています。右の短い斜めの木は3段目の穴付近にあります。

飛んでいる玉がない間は、画面のどこでも左右スワイプで穴を回転できます。床に10個落ちるとゲームオーバーです。

穴と周囲の釘は左右の壁に対して中央へ配置し、右の木は延長、左の木は少し上へ移した短い斜めの形に調整して、跳ね返りと下への通過が両方起きるようにしています。

このリポジトリにはWeb公開用のビルドのみを置いています。Unityのソースは非公開で管理しています。

## プレイ中の物理調整

右上の一時停止 →「玉の動きを調整」で、落ちる強さ・跳ね返り・転がりの抵抗・発射の強さをスライダー調整できます。100%が標準。調整中は玉を止め、「この設定で試す」で同じ盤面から続行します。発射の強さは次の玉から反映されます。設定はそのブラウザに保存され、「元に戻す」で4項目すべて標準へ戻せます。

「落ちる強さ」は質量ではなく、盤面に沿って落ちる加速度を調整します。
